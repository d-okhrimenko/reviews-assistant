# Покращення адміністративного перегляду

## Цілі

- У таблиці адміністративного перегляду відгуків поля «Статус», «Тональність», «Пріоритет» і «Категорія» відображають локалізовані текстові значення замість числових значень enum з API.
- Значення пріоритету та тональності відображаються кольоровими бейджами.
- Критичний пріоритет і негативна тональність мають червоне оформлення.
- Некритичний пріоритет має синє оформлення, а позитивна тональність — зелене.

## Нотатки

- Локалізацію числових enum виконує Angular-клієнт; контракт API не змінюється.
- Зміни стосуються адміністративного списку відгуків.

## Історія

- Базовий функціонал Reviews Assistant — реалізовано Web API, Angular-клієнт, PostgreSQL-міграції, JWT-автентифікацію, Swagger UI та адміністративні сценарії.

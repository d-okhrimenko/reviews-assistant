## Історія

- Бейджі аналітики в картці відгуку — у detail-картці локалізовано статус і категорію та додано бейджі тональності й пріоритету, узгоджені з таблицею.
- Аналіз відгуку через OpenAI — додано strict structured OpenAI-аналіз, збереження метаданих провайдера й моделі, Markdown-інструкції та EF-міграцію.
- Генерація відповіді через OpenAI — додано серверний Responses API, збереження чернетки з моделлю та провайдером, EF-міграцію й редагований Markdown prompt.
- Реалізація AI-абстракції та тестової заглушки — додано контракти AI, Stub-провайдер, ручний аналіз відгуку та генерацію чернетки відповіді в API й UI.
- Покращення адміністративного перегляду — локалізовано enum-значення та додано кольорові бейджі тональності й пріоритету; моделі згруповано за доменами.
- Базовий функціонал Reviews Assistant — реалізовано Web API, Angular-клієнт, PostgreSQL-міграції, JWT-автентифікацію, Swagger UI та адміністративні сценарії.

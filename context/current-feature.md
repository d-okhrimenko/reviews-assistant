# Базовий функціонал Reviews Assistant

## Цілі

- Користувач може надіслати відгук з ім’ям, email і текстом; він зберігається, а користувач бачить підтвердження.
- Адміністратор може увійти в систему та переглянути список відгуків із усіма передбаченими полями аналізу.
- Адміністратор може відкрити деталі відгуку й бачить блок чернетки відповіді та зрозумілу заглушку AI-інтеграції.
- Модель `Review` містить усі поля та статуси, визначені у вимогах.
- Реалізовані публічні endpoints відгуків і авторизовані admin endpoints, зокрема заглушки аналізу та чернетки відповіді.
- Angular-клієнт містить сторінки `/feedback`, `/login`, `/admin/reviews` і `/admin/reviews/:id`.
- Додати Swagger для того щоб демонструвати і тестувати наявні API

## Нотатки

- AI-поля відгуку на підготовчому етапі порожні, а `AnalysisStatus` має значення `Pending`.
- До підключення AI endpoints аналізу й генерації відповіді повертають зрозумілі заглушки.
- Використовувати архітектурні шари Core, Application, Infrastructure та WebAPI; API повертає DTO, а не доменні сутності.
- Для адміністративних endpoints потрібна JWT-автентифікація.
